# 发展对象理论测试 · 学习工具

基于 v6.9 恢复版重建，纯静态单页应用，零后端依赖，部署于 GitHub Pages。

## 功能

- 练习 / 模考 / 背题 / 搜索，全部本地运行
- **听书**：461 题真人语音（edge-tts `zh-CN-XiaoxiaoNeural`），按 `id` 分 10 个分片懒加载
- 进入听书时先短暂使用系统语音，真人语音加载完成后自动切换

## 题库

- 共 461 题，id 1–462（id 107 历史缺失，无重复）
- 题型：单选 185 / 判断 106 / 填空 85 / 多选 49 / 问答 36
- 84 题标记「※ 非考纲」，练习时可一键跳过
- 数据文件：`题库数据_461题.json`（字段 id / type / stem / opts / ans / know）

## 文件说明

| 文件 | 用途 |
|---|---|
| `index.html` | 页面主体（含题库、练习/模考/听书/背题逻辑） |
| `audio_c1.js` – `audio_c10.js` | 10 个语音分片，base64 MP3，共约 57.7 MB |
| `题库数据_461题.json` | 从页面内联 `const DATA` 提取的独立题库备份 |

`index.html` 与 `audio_c*.js` 必须同目录；也可整体下载后离线双击使用。

461 个独立 MP3（按 id 命名，41 MB）见仓库 Release **v6.9-audio** 附件 `devq-voice-461-mp3-20261125_123628.zip`，不占用仓库体积。
